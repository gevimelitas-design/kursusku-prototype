LOCAL VS HOSTING

Local:
- Project dijalankan menggunakan XAMPP.
- URL: http://localhost/kursusku-prototype/
- File project berada di folder C:\xampp\htdocs\kursusku-prototype\
- Digunakan untuk proses pengembangan dan pengujian website.

Hosting:
- Website dapat diakses melalui internet menggunakan domain/URL hosting.
- File project diunggah ke server hosting.
- Website dapat diakses dari perangkat lain selama terhubung ke internet.

Kesimpulan:
Local digunakan untuk membuat dan menguji website sebelum dipublikasikan.
Hosting digunakan agar website dapat diakses secara online.
